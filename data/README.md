# Data

This project uses the **IBM Telco Customer Churn** sample dataset, which represents customers of a fictional telecommunications provider.

## Source

- IBM repository: https://github.com/IBM/telco-customer-churn-on-icp4d
- Direct CSV: https://raw.githubusercontent.com/IBM/telco-customer-churn-on-icp4d/master/data/Telco-Customer-Churn.csv
- IBM documentation: https://www.ibm.com/docs/en/cognos-analytics/11.1.0?topic=samples-telco-customer-churn

The source repository was archived in July 2024. The notebook downloads the CSV to this directory as `Telco-Customer-Churn.csv` if it is not already present.

The raw CSV is intentionally not committed to this repository. Check the source repository's terms and attribution requirements before redistribution. The sample dataset is for education and demonstration, not a real customer database.
