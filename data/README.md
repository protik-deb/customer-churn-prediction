# Data

The project uses the IBM Telco Customer Churn sample dataset.

Dataset information:
- IBM documentation: https://www.ibm.com/docs/en/cognos-analytics/11.1.0?topic=samples-telco-customer-churn
- Expected local filename: `WA_Fn-UseC_-Telco-Customer-Churn.csv`

Place the CSV in this directory to run `src/train.py` locally. The CSV is intentionally not committed to this repository. Check the source's terms and attribution requirements before redistributing a dataset copy.

The notebook can download a commonly used public mirror for learning purposes. Always verify provenance and terms when using third-party mirrors.
